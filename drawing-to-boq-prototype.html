Step 04b

Residual classification

Two different things can be missing, and they are not the same: the category (“is this furniture?”), which a layer name can answer, and the item (“which sofa?”), which only the block name can. A clean layer plus a block called Block_17 still counts correctly — but it cannot be priced. Each residual is rendered as a tight crop and sent to the vision model, which may return a label and nothing else — quantities are never asked for and any number in a reply is discarded before it reaches the pipeline.

Scope of this prototype

Single-storey residential / interior fit-out · architectural only. Inputs are tiered: DXF (A) carries exact geometry and full semantics; vector PDF (B) carries geometry but no layers, blocks or hatch patterns; raster (C) carries neither, so the operator sets scale from two picked points and either traces regions or confirms boundaries the vision model proposes. On every tier the scale is human-supplied and no model output becomes a quantity until a person confirms the geometry it rests on. DWG is detected and refused — see Step 00 for the measured reason. MEP, structural, BIM and multi-storey aggregation remain out of scope and are refused rather than approximated. Classification accuracy on real studio drawings is unmeasured — Phase 0 tests E0 and E1 remain open.
